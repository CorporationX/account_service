# Проверка прав доступа пользователей для запросов

## Проблема

В текущей реализации REST-эндпоинты (например, `/api/balance/replenish`, `/api/balance/authorize`, `/api/balance/clear`) доступны всем аутентифицированным пользователям без проверки их прав. Это может позволить пользователям выполнять операции, для которых у них нет разрешения (например, пополнение чужого счёта или списание средств).

## Предлагаемое улучшение

Необходимо реализовать проверку прав доступа, чтобы каждый запрос выполнялся только пользователями с соответствующими ролями или разрешениями. Например:

- Пользователи с ролью `USER` могут пополнять (`/api/balance/replenish`) или просматривать свой баланс (`/api/balance/{accountId}`), но только для своих счетов.

- Пользователи с ролью `ADMIN` могут выполнять все операции, включая создание баланса (`/api/balance/create`) или списание средств (`/api/balance/clear`).

- Операции, такие как авторизация (`/api/balance/authorize`) или отмена авторизации (`/api/balance/cancel-authorization`), могут быть ограничены для определённых ролей.
