**Проблема:**  
В текущей реализации, если `authorizedBalance` недостаточен для операции (например, списания), сервис выбрасывает `IllegalArgumentException`. Это может быть неудобно для пользователей.

**Предлагаемое улучшение:**

Вместо немедленного выброса исключения система должна:
1. Рассчитать недостающую сумму:  
   ```requestedAmount - authorizedBalance```.
2. Проверить, хватит ли `actualBalance` для покрытия недостачи.
3. Предложить пользователю покрыть недостачу из `actualBalance` через API-ответ или клиентский интерфейс.
4. При подтверждении выполнить операцию, списав недостачу из `actualBalance`.
